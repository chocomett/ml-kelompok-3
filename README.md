# Tugas - Membuat Joblib dan Streamlit App

## Deskripsi

Project ini dibuat sebagai bagian dari tugas untuk melakukan **training Machine Learning model**, menyimpan model menggunakan **Joblib**, dan mengimplementasikan model tersebut ke dalam aplikasi web menggunakan **Streamlit**.

Dataset yang digunakan berkaitan dengan **Credit Card Fraud Detection**, yaitu klasifikasi transaksi kartu kredit untuk menentukan apakah suatu transaksi merupakan transaksi normal atau fraud.

## Dataset

Jika ingin melakukan **training model**, dataset dapat diunduh melalui Kaggle:

[Credit Card Fraud Dataset — Kaggle](https://www.kaggle.com/datasets/joebeachcapital/credit-card-fraud?utm_source=chatgpt.com)

Dataset tersebut digunakan sebagai data utama untuk proses:

1. Data preprocessing
2. Exploratory Data Analysis (EDA)
3. Training Machine Learning model
4. Evaluasi model
5. Menyimpan model menggunakan Joblib
6. Deployment model menggunakan Streamlit

* Python

---

## Cara Menjalankan Aplikasi

Pastikan semua library yang diperlukan sudah diinstall.

```bash
pip install streamlit pandas scikit-learn joblib
```

Kemudian jalankan aplikasi Streamlit:

```bash
streamlit run app.py
```
